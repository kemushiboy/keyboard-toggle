# Laptop Input Lock

[English](README.md) | [日本語](README.ja.md)

Windows ノート PC の **内蔵キーボードとトラックパッド** を一時的にロックするツールです。
外付けのキーボードやマウスはそのまま使えます。1 回実行でロック、もう 1 回実行で解除します。

ノート PC の上に外付けキーボードや MIDI コントローラーを置くときや、
ライブ (VJ/DJ) 中に誤ってノート PC に触れても反応しないようにしたいときに便利です。

## 特長

- 選んだデバイスだけをロック: 内蔵キーボードとトラックパッド (カーソル移動・クリック・タップ・スクロール)
- 外付けのキーボード・マウスはそのまま使える
- もう一度実行するか、タスクトレイのアイコンをクリックすると解除
- 検出画面で、実際に入力しているデバイスを特定できるので他の機種でも使える
- 安全設計: **Windows を再起動すると必ずすべて元に戻る**
- 軽量: 小さな exe 1 つだけ。インストール不要、ネットワーク通信なし

## 動作環境

- Windows 10 / 11 (64bit)
- .NET Framework 4.x (Windows 10/11 に標準搭載)
- 管理者権限 (実行のたびに UAC の確認が出ます)

## 使い方

1. [Releases](../../releases) から最新の zip をダウンロードしてフォルダに展開します
   (例: `C:\Program Files\LaptopInputLock\`)。
2. **`Detect Devices.bat`** を実行します。
   - **内蔵** キーボードで何文字か入力します。
   - **内蔵** トラックパッドの上で指を動かします。
   - 入力があったデバイスが一覧に出ます。内蔵のものだけにチェックを付けて **Save** を押すと
     `devices.txt` が作られます。
3. 外付けマウス (またはキーボード) をつないで、動くことを確認します。
4. **`Toggle Input Lock.bat`** を実行するとロックされ、タスクトレイに盾のアイコンが出ます。
5. もう一度 **`Toggle Input Lock.bat`** を実行するか、盾のアイコンをクリックすると解除されます。

> [!WARNING]
> 外付けのマウスかキーボードが使える状態でロックしてください。使えないと、PC を再起動するまで
> 解除できません。外付けマウスが見つからない場合はロック前に確認が出ます。

## `devices.txt`

ロックするデバイスのインスタンス ID を 1 行に 1 つ書きます。ワイルドカード `*` `?` が使え、
`#` 以降はコメントです。ID はデバイスマネージャーの
**プロパティ → 詳細 → デバイス インスタンス パス** で確認できます。

```text
# Keyboard: HID Keyboard Device
HID\VID_0D62&PID_BABC&COL03\*

# Touchpad: HID-compliant touch pad
HID\DELL0B27&COL02\*
```

全体の例は [`devices.example.txt`](devices.example.txt) を参照してください。

## 仕組み

Windows ではキーボードやトラックパッドを「無効化」できない (「サポートされていません」) ため、
次のように動きます。

1. ロック時に、設定したデバイスを **削除** します (`pnputil /remove-device`)。
2. ロック中はデバイスの変化を監視し、他のプログラムがハードウェアを再スキャンしてデバイスが
   戻ってきたら、約 2 秒以内に削除し直します。
3. 解除時にハードウェアを **再スキャン** します (`pnputil /scan-devices`)。これでデバイスが戻ります。

ドライバーのインストールや設定の書き換えは一切しないので、再起動すればすべて元に戻ります。

### 検出画面が必要な理由

デバイスマネージャーの名前は当てになりません。たとえば多くのノート PC には
「標準 PS/2 キーボード」が表示されますが、実際にキー入力を送っているのは別のデバイス、
ということがよくあります。検出画面では Raw Input API を使い、キー入力やタッチが
実際にどのデバイスから来ているかを調べます。

## 制限事項

- **PS/2 キーボード** (インスタンス ID が `ACPI\` で始まるもの) は、機種によっては再スキャンで
  戻らず、解除に再起動が必要です。検出画面で選ぶと警告が出ます。
- 他のプログラムがハードウェアを再スキャンした直後、最大 2 秒ほどデバイスが使えてしまうことがあります。
- スリープからの復帰でデバイスが再登録されることがあります。自動で削除し直しますが、復帰後に確認してください。
- exe にはコード署名がないため、SmartScreen の警告が出ることがあります。

## ソースからのビルド

SDK は不要です。Windows に付属している C# コンパイラでビルドします。

```bat
src\build.bat
```

リポジトリ直下に `LaptopInputLock.exe` が作られます。アプリの実行中はビルドできません。

## コマンドライン

| コマンド | 動作 |
| --- | --- |
| `LaptopInputLock.exe` | ロック (ロック中なら解除) |
| `LaptopInputLock.exe /detect` | デバイス検出画面を開く |
